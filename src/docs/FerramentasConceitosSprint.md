# **Ferramentas e Conceitos por Sprint**

Mapeamento do que você precisa colocar na sua "caixa de ferramentas" técnica e teórica para cada fase do plano de refatoração do LiterAlura:

| Sprint | Foco Principal | Ferramentas a Dominar | Conceitos e Anotações Chave |
| :---- | :---- | :---- | :---- |
| **Sprint 1** (Segurança) | Documentação de comportamento | Markdown (para o checklist), CLI do seu SO | Testes de Regressão (caixa-preta), Comportamento Observável. |
| **Sprint 2** (Modelo) | Banco de Dados e ORM | PostgreSQL (via pgAdmin ou DBeaver), Spring Data JPA | Anotações (@Entity, @Table), Ciclo de vida do Hibernate (ddl-auto). |
| **Sprint 3** (Service) | Arquitetura do Spring | Spring Core, Container de Beans do Spring | Inversão de Controle (IoC), Injeção de Dependência, Estereótipos (@Service). |
| **Sprint 4** (Principal) | Refatoração e SRP | Java puro (orientação a objetos) | Single Responsibility Principle (SRP), Delegação de responsabilidades. |
| **Sprint 5** (Docs) | Desenho de Arquitetura | Draw.io, Mermaid.js ou PlantUML | Diagrama Entidade-Relacionamento (DER), Modelagem de Casos de Uso. |
| **Sprint 6** (Testes) | Qualidade Automatizada | JUnit 5, Mockito, Spring Boot Test | Mocks vs Stubs, Testes de Integração (@DataJpaTest), Testes Unitários. |
