# **Tools and Concepts by Sprint**

Mapping of what you need to add to your technical and theoretical "toolbox" for each phase of the LiterAlura refactoring plan:

| Sprint | Main Focus | Tools to Master | Key Concepts and Notes |
| :---- | :---- | :---- | :---- |
| **Sprint 1** (Safety Net) | Behavior Documentation | Markdown (for the checklist), OS CLI | Regression Tests (black-box), Observable Behavior. |
| **Sprint 2** (Model) | Database and ORM | PostgreSQL (via pgAdmin or DBeaver), Spring Data JPA | Annotations (@Entity, @Table), Hibernate Lifecycle (ddl-auto). |
| **Sprint 3** (Service) | Spring Architecture | Spring Core, Spring Bean Container | Inversion of Control (IoC), Dependency Injection, Stereotypes (@Service). |
| **Sprint 4** (Principal) | Refactoring and SRP | Core Java (Object-Oriented) | Single Responsibility Principle (SRP), Delegation of responsibilities. |
| **Sprint 5** (Docs) | Architecture Design | Draw.io, Mermaid.js or PlantUML | Entity-Relationship Diagram (ERD), Use Case Modeling. |
| **Sprint 6** (Tests) | Automated Quality | JUnit 5, Mockito, Spring Boot Test | Mocks vs. Stubs, Integration Tests (@DataJpaTest), Unit Tests. |
